# libwkhtmltox

This folder contains the libwkhtmltox library, which is used by the DinkToPdf library to convert HTML files to PDF files.

## What is libwkhtmltox?

libwkhtmltox is a cross-platform library for rendering HTML into PDF, using the Qt WebKit rendering engine. It provides a set of C bindings for the WebKit rendering engine, which can be used to create PDF documents from HTML content.

## Why is libwkhtmltox needed?

The DinkToPdf library requires libwkhtmltox to be installed on the system in order to function. This is because libwkhtmltox provides the HTML-to-PDF rendering engine that DinkToPdf uses to create PDF documents.
